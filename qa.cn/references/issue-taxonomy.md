# QA 问题分类

## 严重程度等级

| 严重程度 | 定义 | 示例 |
|----------|------|------|
| **critical** | 阻塞核心工作流、导致数据丢失或应用崩溃 | 表单提交导致错误页面、结账流程中断、未确认即删除数据 |
| **high** | 主要功能损坏或无法使用,且无变通方法 | 搜索返回错误结果、文件上传静默失败、认证重定向死循环 |
| **medium** | 功能可用但有明显问题,存在变通方法 | 页面加载缓慢(>5s)、缺少表单校验但仍能提交、仅在移动端布局错乱 |
| **low** | 轻微外观或打磨问题 | 页脚错别字、1px 对齐问题、hover 状态不一致 |

## 类别

### 1. 视觉/UI

- 布局错乱(元素重叠、文字被裁剪、出现水平滚动条)
- 图片损坏或缺失
- 错误的 z-index(元素被遮挡在其他元素后面)
- 字体/颜色不一致
- 动画异常(卡顿、过渡不完整)
- 对齐问题(偏离网格、间距不均)
- 暗色模式 / 主题问题

### 2. 功能

- 链接失效(404、跳转到错误目标)
- 死按钮(点击无任何反应)
- 表单校验(缺失、错误、被绕过)
- 重定向错误
- 状态无法持久化(刷新或后退后数据丢失)
- 竞态条件(重复提交、数据陈旧)
- 搜索返回错误结果或无结果

### 3. UX

- 导航令人困惑(无面包屑、走入死胡同)
- 缺少加载指示(用户不知道操作是否在进行)
- 交互缓慢(>500ms 且无反馈)
- 错误信息不清晰("Something went wrong" 但无任何细节)
- 破坏性操作前没有确认
- 各页面交互模式不一致
- 走入死胡同(无法返回、无下一步操作)

### 4. 内容

- 错别字和语法错误
- 文本过时或不正确
- 残留的占位符 / lorem ipsum 文本
- 文本被截断(无省略号或"更多"提示)
- 按钮或表单字段的标签错误
- 缺失或无用的空状态

### 5. 性能

- 页面加载缓慢(>3 秒)
- 滚动卡顿(掉帧)
- 布局位移(加载后内容跳动)
- 网络请求过多(单页面 >50 个)
- 大图未做优化
- 阻塞型 JavaScript(加载期间页面无响应)

### 6. 控制台/错误

- JavaScript 异常(未捕获的错误)
- 网络请求失败(4xx、5xx)
- 弃用警告(即将出现的破坏性变更)
- CORS 错误
- 混合内容警告(HTTPS 页面中加载 HTTP 资源)
- CSP 违规

### 7. 无障碍

- 图片缺少 alt 文本
- 表单输入未关联标签
- 键盘导航失效(无法 tab 到元素)
- 焦点陷阱(无法离开 modal 或下拉)
- 缺失或错误的 ARIA 属性
- 颜色对比度不足
- 屏幕阅读器无法读到的内容

## 单页探索清单

在一次 QA 会话中访问每个页面时:

1. **视觉扫视** —— 拍摄带标注的截图(`snapshot -i -a -o`)。查看是否有布局问题、图片损坏、对齐问题。
2. **交互元素** —— 点击每个按钮、链接和控件。它们是否按其标注执行?
3. **表单** —— 填写并提交。测试空提交、无效数据、边界情况(超长文本、特殊字符)。
4. **导航** —— 检查所有进出路径。面包屑、后退按钮、深链接、移动端菜单。
5. **状态** —— 检查空状态、加载状态、错误状态、满载/溢出状态。
6. **控制台** —— 交互后运行 `console --errors`。是否有新的 JS 错误或失败请求?
7. **响应式** —— 如相关,检查移动端和平板视口。
8. **认证边界** —— 退出登录后会发生什么?不同用户角色呢?
